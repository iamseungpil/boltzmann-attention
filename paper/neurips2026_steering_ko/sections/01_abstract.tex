\begin{abstract}
멀티-툴 도구 호출을 강화하는 기존 네 접근 — tool-aware 파인튜닝, 프롬프트 스캐폴딩, KV-cache 최적화, 활성 스티어링 — 중 본 논문은 활성 스티어링에 속하는 훈련-없는 회전 기반 방법을 제시한다. 카탈로그에서 직접 유도한 per-head 온톨로지 부분공간 $P_{\mathrm{ont}}$ 위에서 질의를 $Q' = Q + \beta Q P_{\mathrm{ont}}$로 회전시키되, \emph{회전의 부호는 도메인마다 다르다}. MetaTool Subtask4와 $\tau^2$-bench retail에서는 $\beta<0$(coverage 억제)이 승리하지만 $\tau^2$-bench telecom에서는 $\beta>0$(증폭)이 $+24.78$pp로 우세하다. 이 도메인 의존성이 기존 활성 스티어링 문헌이 해결하지 못한 ``어느 부호를 쓸 것인가'' 문제를 부각한다. 본 논문은 baseline forward pass 한 번으로 측정 가능한 값 $\bar r_{\mathcal{G}} - \bar r$의 부호가 최적 $\beta^*$의 부호와 일치함을 softmax gradient로부터 직접 증명하고(정리~\ref{thm:beta-star}), 이 예측기를 Adaptive Sign Routing 알고리즘으로 구현하여 4개 Qwen2.5-7B 도메인(MetaTool ST4, $\tau^2$-retail/telecom/airline)에서 부호 예측 정확도와 성능 이득을 동시에 검증한다. 가장 가까운 선행 방법인 SEKA와 AdaSEKA는 정지 key-side 증폭이 방출 도구 상태를 구조적으로 담을 수 없어(정리~\ref{thm:no-memory}) 멀티-툴에서 한계를 가지며, 본 연구의 회전 기반 연산자는 이를 SEKA와 동일한 프로토콜 아래 여러 도메인에서 일관되게 상회한다. 방법은 가중치 학습이 0, 토큰 오버헤드가 0, 저장이 per-head 기저 $(L, H_{\mathrm{kv}}, d, r)$만 추가($\approx 2.6$ MB on Qwen 7B)로 추론 시 저랭크 hook이다. 카탈로그 온톨로지 기저를 feature-shuffled, random, PCA-of-K로 교체 시 효과가 사라져, 이득이 기저 품질이 아니라 회전 연산자 설계와 부호 선택에서 옴을 분리한다.
\end{abstract}
