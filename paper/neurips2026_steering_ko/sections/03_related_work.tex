\section{관련 연구}\label{sec:related}

본 논문의 위치는 표~\ref{tab:positioning}이 정리한 네 접근 축에서 읽어야 한다. 각 축이 무엇을 공략하는지와 본 논문이 어느 빈자리를 채우는지를 차례로 서술한다.

tool-aware finetuning은 가중치를 직접 업데이트해 도구 사용을 학습한다. Gorilla~\citep{patil2023gorilla}는 대규모 API 호출 데이터로 function-calling을 지도학습하고, ToolLlama~\citep{qin2024toolllm}는 RLHF와 bootstrap을 결합해 16000여 개의 실 API를 다루며, xLAM~\citep{zhang2024xlam}은 action model family로 일반화한다. 성능은 강하지만 재학습이 필요하고 카탈로그 교체 비용이 크다. 프롬프트 스캐폴딩은 학습 대신 추론 시 reasoning 체인으로 행동을 유도한다. ReAct~\citep{yao2023react}와 이를 확장한 여러 방법은 관찰-사고-행동 루프로 도구 선택을 구조화하지만 프롬프트 길이와 추론 비용이 task 복잡도에 따라 선형 또는 그 이상으로 증가한다. KV-cache 최적화는 결이 다른 축이다. KIVI~\citep{liu2024kivi}와 StreamingLLM 같은 방법은 KV 캐시 압축과 재사용으로 추론 자원을 줄이지만, 어떤 도구를 고를지 자체에는 개입하지 않아 본 논문의 중심 질문과는 수직이다.

본 논문이 속한 활성 스티어링은 추론 시 attention에 저랭크 개입을 넣는 계열이다. SEKA~\citep{SEKA}와 AdaSEKA~\citep{AdaSEKA}는 contrastive QA 쌍에서 학습한 저랭크 projection을 attention key에 주입해 단일 개념 편집에서 강한 성능을 보이며, ITI~\citep{ITI}와 CAA~\citep{CAA}는 residual stream의 선형 방향을 이용하고, PASTA~\citep{PASTA}는 post-softmax attention을 직접 재조정하며, Focus Directions~\citep{FocusDirections}는 key와 query를 함께 움직여 관련 토큰 쪽으로 집중을 유도한다. 이 계열의 공통점은 훈련 없이 추론 시 저비용으로 행동을 바꾼다는 데 있지만, 동시에 \emph{개입이 정지적}이라는 제약도 공유한다. 같은 저랭크 방향을 모든 디코딩 단계에 걸쳐 동일하게 주입하므로, 이미 무엇을 선택했는지에 따라 개입 자체가 바뀌지 않는다. 단일 개념 편집이나 단일 도구 선택에는 이 성질이 장점이지만, 멀티-툴에서는 coverage 대신 반복을 만드는 원인이 된다. 본 논문은 이 정지성을 문제화하고 그 한계를 이론으로 형식화한 뒤, 그 위에서 \emph{레이어별로 역할을 분리한} 저랭크 개입을 제안한다.

본 논문이 기존 흐름과 갈라지는 지점은 세 가지다. 단일 개념 편집이 아니라 멀티-툴 selection을 직접 겨냥하기 때문에 평가 대상이 coverage와 비반복성으로 바뀌고, 개입을 전 레이어에 균일하게 두는 대신 초기 K와 후반 Q로 역할을 분리하므로 정지 연산자의 구조적 반복 편향을 우회하며, 기저를 contrastive 데이터에서 학습하는 대신 도구 카탈로그의 4-facet 구조에서 직접 구성하므로 재학습 없이 카탈로그 변화에 대응할 수 있다. 이 세 지점은 독립적 디자인 결정이 아니라 한 설계 원리에서 따라온다: \emph{정지 스티어링의 반복 문제를 풀려면 state 또는 layer schedule이 있어야 하며, history-free 조건을 유지하고자 한다면 후자가 남는다}.

벤치마크 선택도 이 문제의식을 따라간다. MetaTool Subtask4~\citep{MetaTool}는 각 질의에 정확히 두 개의 정답 도구를 갖는 497개 프롬프트로 구성되어 순차 coverage와 비반복성을 가장 직접적으로 측정한다. $\tau^2$-bench~\citep{tau2bench}의 retail, telecom, airline 도메인은 정답 도구 수와 난도가 달라 short-horizon과 long-horizon 체제를 같은 프레임 안에 함께 드러낸다. BFCL~\citep{BFCL}의 parallel/multiple subset은 교차 검증용 벤치마크다. 모든 실험은 Qwen2.5-Instruct 계열(주 실험 7B, 보조 스윕 1.5B/3B/14B)~\citep{qwen25}에서 수행된다.
