\section{설정과 기제}\label{sec:theory}

\paragraph{표기와 연산자.}
단일 헤드 self-attention을 고려한다(멀티헤드는 헤드 직합). 레이어 $\ell$에서 질의 $q\in\mathbb{R}^d$, key $K\in\mathbb{R}^{T\times d}$, value $V\in\mathbb{R}^{T\times d_v}$, 교란 key $\hat K = K + E$. 원래 출력 $o(q) = \sum_t s_t(q) v_t$이고 $s_t(q) = \mathrm{softmax}(qK^\top/\sqrt d)_t$. 도구 카탈로그의 4-facet 온톨로지를 Gram-Schmidt로 직교화한 per-head 기저 $B_{\mathrm{ont}}\in\mathbb{R}^{d\times r}$와 사영 $P_{\mathrm{ont}} = B_{\mathrm{ont}} B_{\mathrm{ont}}^\top$를 통해 세 연산자를 정의한다:
\begin{equation}\label{eq:ops}
\underbrace{K' = K + \alpha K P_{\mathrm{ont}}}_{\text{정지 K (SEKA)}},\quad
\underbrace{Q' = Q + \beta Q P_{\mathrm{ont}},\ \beta<0}_{\text{Q-커버리지 (ours)}},\quad
\underbrace{\ell<\lfloor\tau L\rfloor\!:K';\ \text{모든 }\ell\!:Q'}_{\text{레이어 적응형 K+Q (ours)}}
\end{equation}
세 연산자가 같은 $B_{\mathrm{ont}}$를 쓰므로 결과 차이는 연산자 형식에만 귀속된다. 본 논문 전체가 사용하는 분석 가정은 유계 노름 하나뿐이다 (모든 $q,v_t,e_t$에 대해 $\|q\|\le Q_{\max}$, $\|v_t\|\le V_{\max}$, $\|e_t\|\le\rho$). $(q,K,V)$의 결합 분포에 대한 어떠한 제약도 두지 않는다.

\paragraph{핵심 세 주장.}
본 논문의 이론은 세 개의 주장으로 축약된다. 완전한 증명은 부록~\ref{app:proofs}, 따름정리와 조건부 명제는 부록~\ref{app:corollaries}에 있다.

\begin{theorem}[정지 K는 방출 상태를 담을 수 없다]\label{thm:no-memory}
\eqref{eq:ops}의 정지 K-측 연산자를 쓰자. 두 디코딩 히스토리 $h, h'$가 같은 hidden state $x$를 낳지만 이미 방출된 도구 집합에서 다르다면 $K'(h) = K'(h')$이다.
\end{theorem}

\emph{증명.} $K' = K + \alpha K P_{\mathrm{ont}}$는 $(K,\alpha,P_{\mathrm{ont}})$만의 함수이고 셋 다 히스토리 불변이다. $\square$

같은 논증이 AdaSEKA에도 적용된다(입력에 따른 전문가 선택은 $x$의 함수이므로 같은 $x$를 낳는 두 히스토리에서 동일). 이 구조적 성질의 관측 가능한 귀결은 \texttt{repeated\_first\_tool\_rate}의 상승이다(따름정리~\ref{cor:seka-repeat}, 부록).

\begin{theorem}[Q-사영의 기하]\label{thm:q-sign}
\eqref{eq:ops}에서 $\beta<0$일 때 $q'$는 $q$의 온톨로지 성분을 $(1+\beta)$배로 균일 축소하고 직교 성분을 보존한다.
\end{theorem}

\emph{증명.} $P_{\mathrm{ont}}^2 = P_{\mathrm{ont}}$에서 $q' P_{\mathrm{ont}} = (1+\beta)q P_{\mathrm{ont}}$, $q'(I-P_{\mathrm{ont}}) = q(I-P_{\mathrm{ont}})$. $\square$

이것은 exact step-adaptive 제어가 아니라 ``지배적 온톨로지 성분을 덜 신뢰하라''의 가장 단순한 history-free 회전이며, \eqref{eq:ops}의 세 연산자를 \emph{온톨로지 부분공간 위의 회전 기반 스티어링}으로 통일한다.

\begin{theorem}[Attention 출력의 exact integral remainder]\label{thm:bound}
$\phi(\tau) := \sum_t \mathrm{softmax}(\ell(q)+\tau\alpha(q))_t v_t$에 대해 $\hat o(q) - o(q) = L(q, E) + R(q, E)$가 정확한 등식으로 성립하며, 유계 노름 아래에서 $\|\hat o - o\|^2 \le 2\,\mathrm{Var}_s\alpha(q)\cdot\mathrm{Var}_s[V](q) + C_1 \rho^4$, $C_1 = 2 Q_{\max}^4 V_{\max}^2/d^2$.
\end{theorem}

이 정리는 진단 도구다. $L$과 $R$의 완전한 형태와 네 단계 증명은 부록~\ref{app:proof:bound}.

\paragraph{Regime-split 예측.}
레이어 적응형의 $\tau=1/4$ 선택은 ``초기 레이어는 정보 인코딩에 K-imprinting이 안전, 후기 레이어는 출력 수렴에 K 교란이 해롭다''는 경험적 전제 E1에 조건부다(명제~\ref{prop:ladapt-intuition}, 부록). 이 전제와 정리~\ref{thm:no-memory}을 결합하면 K-imprinting의 한계 이득이 시퀀스 길이 $k$에 따라 $(1-\varphi(j-1))$ 꼴로 감쇠하는 regime-split 예측이 따른다(따름정리~\ref{cor:regime}). 이 예측은 \S\ref{sec:exp:performance}의 $\tau^2$-retail smoke 결과와 부록~\ref{app:layer-sweep}의 레이어 경계 sweep이 직접 시험한다.
