## 2. 가설 기반 진단과 QW-WF 도출 과정

### 2.1 배경: QW-PCA 실패

명제 2에서 예측한 Query-Weighted PCA (Σ_Q^{1/2}·Σ_K·Σ_Q^{1/2}의 고유벡터로 회전)가 실험에서 실패:
- Qwen 2-bit: 10.869 (vs PCA 7.987) — 36% 악화
- Mistral 2-bit: 7.473 (vs PCA 6.345) — 18% 악화
- Attention-aware quantizer도 catastrophic (Mistral 44.03)

### 2.2 5가지 가설과 진단 결과

| 가설 | 주장 | 측정 결과 | 판정 |
|------|------|----------|:----:|
| **H2: κ(Σ_Q) 높음** | sqrtm 수치 불안정 | κ=10,333 (max 44,937) | **✅ 확인** |
| H3: q-δk 상관 | 독립 가정 위반 | cos=0.072 | ❌ 기각 |
| **H4: PCA-Q 이미 정렬** | PCA가 이미 attention quasi-optimal | **0.8° (Qwen), 2.5° (Llama), 0.6° (Mistral)** | **✅ 강하게 확인** |
| **H5: 분산 균일화** | QW-PCA가 분산을 균일하게 만듦 | 엔트로피 3.67→4.34 | **✅ 확인** |
| H1: Σ_Q 추정 부정확 | 캘리브레이션 부족 | 미테스트 | — |

### 2.3 핵심 insight

**"Trained transformer에서 key 공분산과 query 공분산의 고유벡터가 자연적으로 정렬 (0.6-2.5°)"**

이것이 의미하는 바:
1. PCA 회전은 attention에 대해서도 이미 quasi-optimal → QW-PCA 불필요
2. sqrtm(Σ_Q)는 κ~10^4에서 수치적으로 불안정 → QW-PCA 악화의 직접 원인
3. QW-PCA 회전이 분산을 균일화 → 양자화에 불리

### 2.4 QW-WF: 실패에서 성공으로

**관찰**: 회전을 바꾸면(QW-PCA) 실패하지만, 비트 배분만 바꾸면(QW-WF) 성공.

**방법**: PCA 회전 유지 + 비트 배분에만 query 정보 활용
```
importance_j = λ_k_j × σ_q_j   (key 분산 × query 가중치)
b_j = B + 0.5 × log₂(importance_j / mean(importance))
b_j = clip(b_j, 2, 4)          (floor=2 유지)
```

**결과**: 3모델 2-bit에서 10-33% PPL 개선, 3-bit에서 1% 개선.
