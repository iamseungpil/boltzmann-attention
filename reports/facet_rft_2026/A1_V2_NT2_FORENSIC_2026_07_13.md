# A1-v2 nt2 전수 per-step 포렌식 — 항상-FAIL vs flip 원인 확정 (2026-07-13)

> 데이터: `genv2_a1v2`(trial A·db 0.702) + `genv2_a1v2_r3`(trial B·db 0.667) = 같은 arm 독립 nt1 × 2 (nt2 누적 0.684·n=228).
> 방법([[08]]): 교차표(PP/FF/flip) → FF 23 전수 per-step(A 정독+B signature 대조) + flip 26 전수 분기 분석(최초 분기 스텝·인과·가드 구제성) — 병렬 4에이전트·49 태스크-궤적 정독. 종료사유: FF 46런 중 too_many_errors 1(t36-A)·나머지 user_stop·crash 0.
> 선행: `A1_V3_PROBE_FORENSIC`(v3 13건) · `COVERAGE_LOOP_DESIGN` §1b(교차 arm). 본 문서 = **v2 arm nt2 완결판·레버 우선순위 재정렬 근거**.

## 0. 요지
1. **nt1 flip율 = 26/114 = 23%** (P→F 15·F→P 11). 점추정 ±3.5pp는 구조가 아니라 표집.
2. **FF 23 = 구조적**: 신규 분석 17 중 ~9개가 **결정론적 재현**(두 런 같은 슬롯·같은 오답값) — nt를 늘려도 안 닫힘·레버 필요.
3. **flip의 지배 기전**: 표면 분기는 user-sim 25/26이나, 인과는 "노이즈 하 접지-회복력 부재" — **B-win 패턴이 단 하나로 수렴 = write 전 후보 record 전수 열거(read-all)**. 전수 열거가 coverage+BIND+PROV를 동시에 닫음(t2·74·81·107·22 실증).
4. **레버 우선순위 재정렬**: ①COV/L2 계열 read-forcing(최대·FF 4-5 + flip 구제 7-8) ②L10+disamb 확장(동반품목·same-order·속성대조 — FF 5-6) ③L3(FF 3·"123 Broadway"가 **태스크 교차 model-prior**로 확정) ④L4(FF 3) ⑤L7(1-2). 의미(learn/ASK) 잔여 5-7·infra 3-5.
5. **"123 Broadway" = 교차-태스크 결정론 날조**: t97과 **t112**가 서로 다른 태스크·두 독립 런 전부에서 *같은 주소*를 날조 — 모델 prior의 자기복제. L3 사정권 재확인(v4에 기구현).

## 3. flip 26 종합
### 3a. P→F 15 (A pass→B fail)
- 표면 분기: user 14/15·assistant 1(t58). 인과: **회복실기 6**(5·29·55·69·91·101) / agent-확률 5(58·66·104·106·111) / user-sim 4(15·21·82·83).
- **가드 구제 YES 7+조건부 1**: **L2/L2-ref 5-6**(5·82·83·91·111·(104)) · COV 1(55) · L7 1(66). NO 7 = L4/learn(29·58·106)·의미 피벗(21·69)·내용-predicate disamb(101)·**user-sim 의도왜곡(15=infra 분리)**.
- t58 v2-실패 기전: L4 없이도 **에이전트 자신이 제약(capacity) 위반 후보 제시**→user 승인 — v3의 L4-치환 파손과 별개의 2차 모드. 복합제약 변형 = 이중 취약.
### 3b. F→P 11 (A fail→B pass)
- 인과: agent-확률 10 / user-sim 1(92). **B-win 패턴 단일 수렴 = 후보 전수 열거(read-all)** — coverage(81·74·107)+BIND(107)+PROV(22 revert용 옛값 보존)를 동시에 닫음.
- t81(에이전트 주도 열거) vs t92(user-sim 지속성 덕) — coverage는 두 비결정 채널 중 하나가 우연히 켜져야 닫힘 = **결정론 read-강제(COV) 필요의 직접 실증**.
- t64: B pass조차 모델 선택이 아니라 **메뉴 외부화→user가 선택**. gold tie가 명세상 결정불능 → **tie는 enumerate-ASK가 정도**(min_price override 방향 보류 — `test_l4_tie` 한계 판단과 합치). t20: 모델이 자발적으로 keep-제약 필터 적용 성공 — 제약 필터는 결정론으로 닫히는 층(L4-F2 지지).

## 4. 횡단 패턴 [M]
1. **read-all 승리 패턴**(F→P 4/11+P→F 회복실기 6): 전수 열거가 3개 실패축을 동시 폐쇄 — **COV 루프+L2 GET-forcing = 최대 가치 레버쌍**으로 승격.
2. **"123 Broadway" 교차-태스크 prior**: t97·t112 × 양런 = 4회 동일 날조. 모델 prior의 결정론 재현 — L3 (v4 기구현) 가치 상향.
3. **user-sim = 오염 채널이자 노이즈원**: 오확인·순응(2·74·81·92)·의도왜곡(15)·현물 날조(98-B·54)·확인+즉시STOP(112-B) — **집계 infra-noise 분리 규약 필수**·"사용자 확인"은 검증축 아님(재확인).
4. **FF의 결정론 재현 ≈ 9/17**: t7·27·31·57·93·100·109(+99·102 부분) — temp0 prior가 같은 자리에서 같은 오답. nt 증가로 안 닫힘.
5. 생성 열화 1건(t36-A raw `<|im_start|>` 누출+too_many_errors) — 관찰 기록.
