## 0. 한 문단

B4 아크는 통행료를 −40% 싸게 만들었는데 pass가 안 움직였다. 실패 40건을 **원인 클래스**로 나누고
각 클래스를 **결정 스텝**에서 읽으니 이유가 나왔다 — **실패의 약 4분의 3이 "에이전트가 자기 몫의
행동을 다른 주체에게 넘기고 종료"** 로 끝난다. 넘기는 대상이 사람 상담원이거나 손님일 뿐이다.
통행료는 그 탈출구를 지키는 문이므로, 문을 싸게 하면 **더 싸게 탈출한다**(이관 호출률 37.5% → 42.2%).
그래서 이번 설계는 통행료를 *짧게* 하는 방향을 버리고, **이양이 성립하기 위한 전제를 접지**한다.
다섯 레버 전부 술어가 닫혀 있고, **무엇을 할지 정하지 않으며**, 판단은 원래 권위자에게 남긴다.

## 2. 설계 원칙 (이 문서의 모든 레버가 지킨다)

1. **권위 소재를 바꾸지 않는다.** *"나는 어느 카드를 원하는가"* 의 권위자는 손님이고, *"이 구매가 어느
   범주인가"* 의 판단자는 LLM이다([[52]]·[[22]]). 엔진은 **권한 없는 판정을 막을 뿐** 대신 판정하지 않는다.
2. **닫힌 술어만.** 다섯 레버 전부 궤적 사실·도구 출력·레지스트리 대조만 본다.
3. **집행이지 표면화가 아니다.** 비강제 신호는 작업 중 무력하다(Recuse Signal 2606.06460: 0/40 · [[42]] ·
   그리고 fit note의 *"verify the cited source docs"* 가 실제로 무시된 이번 실측).
4. **행동을 강제하지 않는다.** [[06]] write 강제 금지선 · 2607.22868 정리 1(liveness 집행 불가) —
   전부 **사전 조건**으로만 표현한다.
5. **새 게이트를 증식하지 않는다**([[05]]). L2는 기존 `arg_producers` 확장, L1″-b는 기존 접지 검사
   (`_gflags`)의 **구멍 메우기**다.

## 4. [[05]] 3질문 ([[17]] 상설 의무)

**Q1 도메인 어휘가 순증하는가?**
- L1″·L4·L5: **아니오**. 규칙은 *"미검증 입력으로 후보를 지우지 않는다"*, *"하지 않은 것을 했다고 말하지
  않는다"*, *"이관 전제를 궤적에서 검증한다"* — 도메인 명사 0. 카드별 자격 목록·도구 목록은 **KB/레지스트리에서
  읽는다**(A2 리터럴 아님).
- L2: 기존 선언 재사용. **L3**: A2에 노드 라벨·변별어가 들어가나 **전량 파일명·코퍼스 기계 도출** = env 도출
  ⇒ [[23]] opex 0 · **gold 참조 0**(어느 노드가 정답인지 보지 않고 생성).

**Q2 유동 판단을 동결하는가?**
- L1″: **아니오** — 어느 카드가 최선인지 엔진이 정하지 않는다. 후보가 손님에게 온전히 도달하게만 한다.
- L5: **아니오** — 이관 여부는 모델이 정한다. 전제 충족만 요구한다.
- L4: **아니오** — 무엇을 할지는 모델 몫. 하지 않은 것을 했다고 말하는 것만 막는다.
- L3: **아니오** — 노드 선택은 모델 몫, 엔진은 계수만.

**Q3 도메인 전이 시 무엇을 다시 쓰나?**

  **L3 = 노드 선언을 도메인마다 재생성하되 파일명에서 기계 생성이라 저작 0·자동**.

## 6. 위험 · 안 고치는 것

- **필요조건이지 충분조건이 아니다.** 카드에서 정답을 보고도 다른 선택 1건, 미신청 1건이 남는다.

## 8. 이 설계에 이르며 철회·정정한 것

1. **"지배 결함 = 정보를 다 갖고도 말로 바꾼다"** → sim 단위 4/40. 근거였던 reach scan 79%는 *도구 이름 한

2. **"카드 = 자기-정박·F2b"** → 철회. 엔진은 문서 축자를 참되게 보고했고, 오류는 **범주 소속 판정**(F3·열림).
3. **"C1은 닫힌 술어가 없으니 경계"** → 부분 철회. 무시된 것은 *산문 note*이지 *검증 필드*가 아니다(C45 선례).
   최종 형태는 핀 계약이 아니라 **권위 가드**(§3 L1″).
4. **"열거하면 통과"** → 반증. 열거 *개수*는 통과와 무관(64% vs 57%)이고, 결정하는 것은
   **마지막 안내에 gold가 있었는가**(18/3 vs 0/8).
5. **격리 프로브 0/30** → 무효. "MIN" arm이 문서 69개·75,561자로 **FULL보다 부하가 컸고**, 질문도
   *고르기*였는데 과업은 *제시하기*였다. C124의 A_minimal이 설계에 아예 없었다.

1. **L5-b(해금 미호출 도구 0)의 강도** — 이건 사실상 *"문서화된 도구를 먼저 써라"* 라서 [[06]] write-강제
