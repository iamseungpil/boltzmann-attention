# AX33 런 설계 (사전등록) — r6 처방 스택의 합성 검증 (2026-08-02 초안 v1)

> **상태 = 사전등록 초안 · 발사 게이트 미충족**(아래 §6 — ax32 최종 판정·r6 리뷰·조사 4건 선결).
> 모(母)설계 = `AX32_MIDRUN_PRESCRIPTIONS_DESIGN_2026_08_02.md`(r6) · 대조 기준 = ax32(p1 확정·p2 진행).
> 규율: 합성-우선([[19]])·pass 점수 [D]·판정=표적 기전 소멸 per-case + Δspurious ≤ 0 + 짝 McNemar 병기.
> 이 문서는 **ax32 완주 전 수확분으로 사전등록**한 것 — 완주 후 채울 칸은 ⟦슬롯⟧으로 명시.

## 1. 목표 (한 줄)

ax32에서 준결정으로 확정된 표적 7+2건에 대해, r6 처방(P1·P2·P5·P7·P8·P9·P10)을 **한 스택으로 합성
탑재**하고 표적별 기전 소멸을 짝 대조로 검증한다. 레버 승리 2건(007·008)의 무회귀가 동시 조건.

## 4. 실행 계획

1. **무료 선결(병행 가능·지금 시작 가능)**: ⓐP4 정합 조사(023 rebate·019/026 discrepancy 문구·024/025
   Bronze-당위) ⓑP2 구조 신호 조사(bm25 스코어 판독 가능성·quotes-류 필드) ⓒ감사 C(ARG_SCHEMA dark —
   give 스키마 vs 배선·V7 동형 판별) ⓓdbdiff 패치-적재 모드(029 킬러 확정).
2. r6 리뷰 승인 → 구현(P9→P7→P2→P8→P1→P10→P5) + 오프라인 픽스처 전건 + x45(OFF 바이트-동일).
3. **스모크**(표적 6태스크: 010·012·015·018·028·040 · nt1 · ~30분): 신규 레버 전종 라이브 발화 확인
   (beat 태그·[[30]] 규율 "스모크 없이 full-run 금지").
4. 본런 ax33: front32 × nt2 · GPU 2분할 · 체인(p1→p2)·pass마다 envcheck+x44+영속화(ax32 러너 재사용·
   태그 `bank_ax33p{1,2}_gpu{0,1}_YYYYMMDD`).
5. 수확: x38/x46 포렌식 → 표적표(§3) 판정 → 백로그 원장 갱신.

비용: ax32 동급(user-sim gpt-5.2·64sim/pass — Y1 실측 $0.033/sim 기준 pass당 ~$2·[[09]] 승인 필요).
