이고, 055·063 은 **전달 유형과 무관하게 전부 0**이다. ⇒ ⓓ 는 지금 데이터로 **상한이 열려 있다는 근거가 없다**.

## 1. 어떻게 셌나 (파싱 0 · 존재 확인만)

- 자리 = **우리 도구 출력**이 후보를 2개 이상 배달한 메시지. 식별은 우리 엔진이 붙이는 표식
  `[checks] applied:`(`t2_compute.py:493`)로만 한다. ⚠이 표식 없이 *"eligible"* 문자열로만 걸렀던 1차판은
  **KB 검색 결과까지 빨아들여 자리가 140 개**로 부풀었다(대부분 문서 본문).
- 후보 이름은 **우리 A2 카드표의 닫힌 집합**(13). 도메인 산문에서 뽑지 않는다([[59]]).
- 판정 = 그 다음 어시스턴트 발화에 우리 이름이 몇 개 등장하나: **≥2 = 넘기기 · 1 = 밀기 · 0 = 무언급**.
  낱말 경계는 `t2_probe._word_in` 정본(`EVERGREEN ⊃ GREEN` 오적중 방지·C515).
- sim 안에 자리가 여럿이면 **sim 단위로 접어서** 다시 센다(중복 계수 방지).

## 2. 결과

### 2-1. 카탈로그 4 태스크 (sim 단위)
```
task_003   넘기기≥1  pass 2 / fail 3 = 0.40      밀기만  pass 2 / fail 7 = 0.22
task_024   넘기기≥1  pass 2 / fail 14 = 0.12
```

003 의 0.40 ↔ 0.22 는 **2/5 대 2/9** 다 — 이 표본에서 갈랐다고 말할 수 없다.

### 2-2. 전체 (sim 단위·⚠태스크가 섞여 있어 해석 불가)
```
넘기기≥1  pass 14 / fail 48 = 0.23
밀기만    pass 21 / fail 35 = 0.38
무언급만  pass  1 / fail 28 = 0.03
```
넘기기가 **더 낮다**. 그러나 이 수는 읽으면 안 된다 — 태스크마다 **옳은 행동이 다르다**(002·006 은 밀기
1.00 = 에이전트가 실행해야 하는 흐름). [[08]] 상 집계에서 결론 직행 금지. 여기 싣는 이유는 *"넘기기가
일반적으로 낫다"* 는 **반대 방향의 예단도 근거가 없다**는 것을 보이기 위해서다.

## 3. 결정적 반례 — 넘겼는데 졌다 (003·t7328 t0)

에이전트가 세 장을 **구별 속성까지 정확히** 열거했다(축자):
```
### Silver Rewards Card
- Annual Fee: $0.00
- Cash Back: 4.0% on travel purchases
- Maximum Credit Limit: Up to $100,000
- Purchase Protection: Yes
- Foreign Transaction Fee: 0.0% (with Rho-Bank+ subscription)
```
이는 N97 의 **pass 궤적이 준 것과 같은 정보**다. 그런데 손님(user-sim)은 **Gold Rewards Card** 를 골랐고
gold 는 `Silver Rewards Card` 라 **reward 0.0**. ⇒ 같은 정보를 넘겨도 손님의 선택이 갈린다.

⚠[[21]] 상 이것을 *"user-sim 변동"* 으로 종결하면 안 된다. 남는 물음은 **에이전트 쪽으로 환원된다** —
손님의 규칙은 *"최소 연회비 · 동률이면 최고 캐시백"* 이고 후보는 Gold(전 구매 2.5%) ↔ Silver(여행 4%·기본 1%)
다. **손님의 지출 패턴(여행 중심)에 맞춘 기대 수익을 계산해 주지 않으면** 그 동률은 손님 쪽에서 임의로
갈린다. 즉 003 의 잔여는 전달이 아니라 **선택 근거의 계산**(§1-4 argmin/argmax)에 있다.

## 4. present 폐기와의 관계 (규칙 0)

C34 축자: `candidate_summary`(`T2_PRESENT_READS`)는 **에이전트가 부르지 않은 도구를 엔진이 대신 호출**해
주입했고 그래서 폐기됐다. 같은 항목이 *"`nested`·`calc`·gate-kinds·`REGEN_FEEDBACK` 은 위반 아님
(**에이전트 자신이 가져온 내용 위에서 동작**)"* 이라고 못 박는다. ⇒ **에이전트가 이미 호출한 fit 도구의
산출을 다시 표면화하는 것은 규칙 0 위반이 아니다**(출처 축). 다만 present 의 **부작용 실측**은 그대로
경고로 남는다: pass 0.547 → 0.576 이면서 **미조회 날조 5.6% → 10.4%** · 조회 2.62 → 0.48(C31 계열).
⇒ 이 축을 다시 만들면 **Δ날조·Δ조회를 종점과 동급으로** 재야 한다(등대 §1.3).
