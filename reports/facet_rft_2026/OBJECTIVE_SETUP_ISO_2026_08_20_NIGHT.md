## 1. 팔과 사전 고정 판정

```
A_task   후보표 + "올해 <범주>에 $<금액> 쓴다"
C_nopat  후보표만 (패턴 없음)              ← 부정통제
D_hint   A_task + **일반식 한 문장**: "돌아오는 값 = 해당 요율 × 금액 − 연회비"

판정   A≈C → 패턴 미사용 · D≫A → 목적함수 설정 결손 · D≈A 이고 둘 다 낮음 → 피연산자·산술 경계
       차이는 8/48(≈17pp) 이상만 읽는다
```

## 2. 결과

```
A_task  18/48 (0.38)      C_nopat  5/48 (0.10)      D_hint  20/48 (0.42)
상수 답 상한 0.29 · 후보 밖 이름 **0/48**(날조 없음)
```
- **A ≫ C (+13/48)** ⇒ 패턴을 **쓰기는 한다**(x440 에서는 이것조차 판정 불능이었다).
- **D ≈ A (+2/48)** ⇒ **식을 말해줘도 안 된다**. 사전 고정 판정문상 *"목적함수 설정 결손"* 이 아니라
  **그 다음 단계(피연산자 선택·계산)의 경계**다.

### 2-1. ★계열이 결과를 반으로 가른다
```
personal    A 4/24 (0.17) · C 4/24 (0.17) · D 4/24 (0.17)   ← 세 팔이 **완전히 같다**
business    A 14/24 (0.58) · C 1/24 (0.04) · D 16/24 (0.67)  ← 패턴이 +13 · 식이 +2
```
personal 쪽에서는 **패턴도 식도 값이 0** 이다. 그 절반의 정답은 대부분 `Platinum Rewards Card`
(기본 10%·연회비 $200)인데 모델의 최빈 답은 `Silver Rewards Card`(기본 1%·**travel/software 4%**)로
21~24/48 이다.

⇒ 기전은 하나로 읽힌다: **범주 보너스가 붙은 카드를 고른다**. 금액을 곱하지도, 연회비를 빼지도 않는다.
   금액이 작거나 business travel/software 처럼 보너스가 실제로 이기는 구간에서는 맞는 답이 나오고,
   금액이 커져 기본 10%가 이기는 구간에서는 그대로 틀린다.

### 2-2. 024 와의 정합
`C560` 이 남긴 단일 관측(024: 모델이 순이익 **최하위** `Business Platinum`(150) 선택 · 정답 `Business
Bronze`(400))은 같은 기전의 다른 얼굴이다 — 그때는 *"base 1.5% 가 최고"* 라며 **요율만** 봤다.
방향(비싼 카드 ↔ 싼 카드)은 사례마다 다르지만 **공통은 곱셈과 뺄셈을 안 한다**는 것이다.

## 3. [[62]] 관점의 결론

```
① 격리에서 되나          → 아니다(A 0.38·personal 0.17)
② 전달만으로 되나        → 아니다(패턴을 줘도 personal 은 0.17 그대로)
③ 식을 말해주면 되나     → 아니다(D−A = +2/48 · personal 은 0)
⇒ 결정론이 정당화되는 자리 = **후보별 net 계산과 argmax** 그 한 단계
```

★단 **최소한**이어야 한다([[62]]). LLM 이 계속 하는 것: 범주 소속 판정(열린 술어·[[22]])·후보 자격·

# §5 값을 계산해서 주면 고른다 — `E_values` 47/48 (2026-08-20 밤 · 같은 48 문항)

> 산출 `x441_values1.json` · 로그 `x441_values_20260820.log` · 다른 팔은 **다시 안 돌렸다**(`--arms` 로 분리)

## 5-1. 팔 정의

`E_values` = `A_task` 와 **모든 것이 같고**, 각 후보 줄 끝에 그 손님에 대한 값 한 개를 붙인다:
```
- Platinum Rewards Card: annual fee $200.0 · base rate 10.0% · scope all · estimated return for this customer: $600.00
- Silver Rewards Card:   annual fee $0.0 · base rate 1.0% · category rates: software 4.0%, travel 4.0% · … : $320.00
```
이것이 **최소 결정론 단계의 모사**다 — 엔진은 **곱셈·뺄셈**만 하고, **정렬도 안 하고**, *"정답은 X"* 도
말하지 않는다([[62]]). 라이브 도구는 지금 **요율 조회에서 멈춘다**(`t2_compute.py` C204/D6 축자:
*"조회만 한다(값 생성·선택·순위 0)"*) — 그 경계를 **한 칸** 옮기면 무엇이 달라지는지를 잰 것이다.

## 5-2. 결과

```
C_nopat   5/48 (0.10)     ← 부정통제(패턴 없음)
A_task   18/48 (0.38)     ← 패턴만
D_hint   20/48 (0.42)     ← 패턴 + 목적식 한 문장
E_values 47/48 (**0.98**) ← 패턴 + **후보별 값**
```
`E_values − A_task = +29/48 (+60pp)` — 판정선(8/48)의 3.6배다. 최빈 답 비율도 **0.29** 로 떨어져
(A_task 0.44 · C_nopat 0.50) **상수 답이 아니라 값을 따라간다**.

## 5-3. 유일한 오답이 말하는 것

```
personal · media_advertising · $500   정답 Gold(12.50) · 모델 Bronze(5.00)
why: "highest estimated return among the cards **with no annual fee** and applicable scope"
```
값은 정확히 읽었는데(자기 답의 `amount_back` = 5.0 = Bronze 의 값) **연회비 0 인 카드로 후보를 먼저
좁혔다**. Gold 도 연회비 0 인데 그것을 못 본 것이다. ⇒ 남는 잔여는 계산이 아니라 **자기가 만든 부가
조건**이고, 48 중 1 이다.

## 5-4. [[62]] 결론 갱신

```
① 격리에서 되나            아니다 (0.38)
② 전달만으로 되나          아니다 (personal 0.17 그대로)
③ 식을 말해주면 되나       아니다 (+2/48)
④ 값을 주면 되나           **된다 (0.98)**
⇒ 결정론이 정당화되는 자리 = **후보별 값의 계산 그 한 단계**. 그 이상(정렬·선택·발화)은 넘기지 않는다.
```

⛔**이것은 pass 가 아니다**([[69]]). 합성 격자에서 **능력의 위치**를 특정한 것이고, 라이브에 얹으면
   그때는 `reward` 짝 A/B 로만 판정한다. 그리고 얹기 전에 **부작용 계량이 선결**이다 — 같은 자리에서
   `present` 가 pass 를 사고 **미조회 날조 5.6% → 10.4% · 조회 2.62 → 0.48** 을 팔았다(C34/C31).
   최소 계량 3종: **Δ날조 · Δ조회 · over-action**(등대 §1.3 Δspurious ≤ 0 · [[70]] 태스크별 부호표).
