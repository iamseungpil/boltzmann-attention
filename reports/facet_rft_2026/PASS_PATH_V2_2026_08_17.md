## §3 경로 (P0 → P5) · 각 단계는 앞 단계의 게이트를 통과해야 시작

### ⛔P0 편성 확정 — **B안**(사용자 지시 2026-08-17 밤·축자 *"최종 census 런은 B 로 간다"*)

> 2팔인 이유는 **비교 대상이 없어서**다: 옛 census(08-10)는 낡았고(22 중 8개 ≥0.25 상향),
> 최근 런은 23 태스크뿐이며 **구성이 런마다 다르다**(런처가 얹는 플래그). ctl 팔이 있어야
> ⑴새 census ⑵레버 인과가 **동시에** 나온다. 다만 전수 2팔(190 sim·≈21h)은 비싸다.

| 안 | 편성 | sim/시간 | 판정 |
|---|---|---|---|
| A 2팔 전수 | 95×2 | 190 / ≈21h | 인과 전 범위 · 비쌈 |
| **B (확정)** | **treat 95 + ctl 40** | **135 / ≈15h** | 절대 pass 확정 + 표적 인과 |
| C treat 단독 | 95 | 95 / ≈10.5h | **인과 0** ⇒ 레버 공로 주장 불가 |
| D 순차 2박 | 190 | 2박 | A 와 동일 · 드리프트 위험 |

**ctl 40 의 구성 — 원안을 하나 고친다**(같은 비용·[[57]] 준수):

| 몫 | n | 왜 |
|---|---|---|
| 선택축 표적(A버킷·`x365`) | **24** | L-V 가 실제로 닿는 전부(25 − 069 표적금지) |
| 019 도구-지급 가족 | **6** | 019·020·022·027·028·029 |
| **비표적 회귀 감시**(사전 고정·무작위) | **10** | ★원안(표적 40 전부)은 **해악을 원리상 못 잰다** |

> 원안의 전제 *"비표적은 레버가 발화 안 하니 ctl≈treat"* 는 **가정이지 측정이 아니다**. 오늘
> 반례가 나왔다 — C516 군 파싱 수리는 **전 태스크**의 군 목록을 바꾼다(024 는 이제 `credit_cards`
> 축이 하나 더 생긴다). 설계서 §7 리뷰 ②가 *"회귀 무해 판정은 라이브에서만"* 이라고 못박았으므로
> 40칸 중 10칸을 회귀 감시에 쓴다. 표적 인과는 30 태스크로도 선다(격리 n≥20 바와 같은 자리수).
> 비표적 10 은 **정렬 후 균등 간격**으로 사전 고정하고 런 전에 목록을 축자로 기록한다(사후 선택 금지).

**구성 핀**(⚠오늘 발견): `go_stack.sh` 에 **없는** 플래그를 런처가 얹고 있다
(`T2_ACTION_INDEX`·`T2_SEARCH_ON_PROCEED`·`T2_DECISION_CARRY`) ⇒ 양팔의 env 를 **축자로 덤프**해
`sim_results/` 에 같이 영속한다. 이것이 없으면 ctl 이 baseline 구실을 못 한다.

### P0 — **새 baseline** (유료 1회 · 최우선 · 승인 필요)
- **왜 먼저인가**: 74 태스크가 최근 데이터가 없다. 표적을 모르면 어떤 레버도 기대값을 못 낸다.
  오늘 하루의 교훈이 정확히 이것이다(낡은 census 로 표적을 잡아 055 한 축에 하루를 썼다).
- **편성**: 97 태스크 × **nt=1** = 97 sim(≈11시간). 구성은 **현행 런처 구성으로 핀**한다
  (⚠`go_stack.sh` 에 없는 플래그를 런처가 얹고 있다 — `T2_ACTION_INDEX`·`T2_SEARCH_ON_PROCEED`·
  `T2_DECISION_CARRY`. baseline 은 그 구성을 **축자로 기록**한다).
- **산출**: ⑴태스크별 pass ⑵`x350` 전수 포렌식(종료사유·결정점·군 선택·실패 유형) ⑶새 표적 목록.
- **게이트**: 이게 없으면 P2·P4 의 표적을 못 정한다. **P0 없이 다른 유료 런 금지.**

### P2 — **합성 A/B** (유료 1회 · P0·P1 통과 후)
- treat = P1 에서 확정된 레버 **전부 동시**([[19]]·끄지 않는다), ctl = P0 구성.
- 편성: P0 이 뽑은 **표적 태스크 40개 × nt=2 × 2팔 = 160 sim**(≈18시간).
- 1차 종점 = **pass**(reward). 부작용 = 회귀 태스크 pass·over-action·지연·CWE.
- **게이트**: 표적군 pass Δ ≥ +5 태스크 ∧ 회귀 손실 ≤1 → P4 로. 아니면 P3 로 되돌아간다.

### P4 — **97 전수 확정 런** (유료 1회 · 리더보드 규격)

## §5 규율 변경 (오늘의 실패에서 나온 것)

1. **유료 런은 *합성 확정*과 *baseline* 에만 쓴다.** 단일 레버 검정용 유료 런 금지 — 오늘 3회를
   그렇게 쓰고 확정 0을 얻었다.
2. **유료 팔에 들어가려면** 무료 격리에서 ⑴부정통제 유효 ⑵표적 Δ ≥ +5(n≥20) ⑶회귀 손실 ≤1 을
   **전부** 통과해야 한다.
3. **구성 핀**: 런마다 `go_stack.sh` + 런처가 얹는 플래그를 **축자로 기록**한다(오늘 불일치 발견).
4. **표적 분류는 사후 재도출**(층화 금지·등대 §1.3) — 사전 분류는 편성용으로만.
5. 결과는 종료 즉시 영속 → `git add -f` → **tracked 확인**([[30]]).
