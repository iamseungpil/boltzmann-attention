## §1. 발명의 핵심 (한 문단)

도구-사용 LLM 에이전트에서 LLM의 역할을 **유한한 최소 기능군의 formalize**(턴-선언·ask-선언·
완료-보고·유저-위임 지시·근거 인용·유저-발화 분류)로 한정하고, 결정론 엔진은 **선언의 형식
검증(스키마→문법 컴파일)·선언↔구조-이벤트 정합 검증·실행/라우팅만** 수행한다(산문 해석 0).
이때 ⑴ 그 최소 기능군을 **도출하는 판정 절차**(닫힘 배터리)와 ⑵ formalize 기능의 실패를
**3분기 triage**(선언-강제 시험 → 격리-replay 시험 → 잔존=learn/ASK)로 분류해 해법 채널을
배분하는 절차를 갖춘 시스템+방법. 경계 자체가 아니라 **경계-도출·배분 절차**가 발명이다.

## §2. 청구 골격

**독립항 1 (시스템·선언-우선 에이전트)**
(i) 선언 스키마 저장부(A2 `formalize_spec`: base=도메인-불변·domain=내용만)
(ii) **스키마→디코딩 문법 컴파일러**(선언 필드 존재·타입·enum을 생성 시점에 하드 보장)
(iii) LLM formalize 채널(봉투: turn_type·ask{slot,reason}·done_report·instruct_user_run·
     evidence_quote / user_act 분류)
(iv) 결정론 검증기 — **선언↔구조-이벤트 정합 규칙의 폐쇄 목록만** 검사(목록 밖 검사=위반·
     자유 산문 불투명)
(v) 결정론 실행기/라우터(calc·필터·참조 치환·turn-policy: user_act×DAG×slot×게이트)
(vi) 위반 시 처방은 폐쇄 메뉴(재생성·치환·deny+사실·표면화·read-강제)로 한정.
(vii) **★엔진 2분할(2026-07-30 사용자 지시·§13d)**: (i)~(vi)의 엔진은 **도메인별 수정 0**이고,
     도메인 적응은 **①도구 구현체 ②A2-CORE 채움 ③A2-EXT** 세 경로로만 이루어진다.
     **A2-EXT는 닫힌 3종**으로 한정 — E1 계산 명세·E2 도구셋 제공([[16]] §8 데이터 접근=정당)·
     E3 스키마-파생 상수. 그 밖의 도메인-특화 스펙은 CORE 흡수 또는 폐기(현 EXT 19키 재분류:
     허용 10·CORE 흡수 7·폐기 2·UNCLASSIFIED 0). ⇒ **기능군 상한이 종류 수준에서 고정**.

**독립항 2 (방법·경계 도출 + triage)**
(a) 후보 술어마다 **닫힘 배터리** 적용: P1(구조-이벤트 정의가능성)·P2(프록시 검사)·
    P3(의미-보존 변이 flip-프로브·h(π) 궤도-조건부 엔트로피·Wilson 판정)·R(처방 폐쇄)·
    Q3(정당화의 일반성) → 결정론-강제 가능 집합과 **LLM-formalize 필요 최소 기능군**을 분리.
(b) formalize 기능의 실패에 **순차 triage**:
    ⑴ 선언-강제 시험(무료): 선언 채널 부과 후 실패 소멸 → **인터페이스-유발**(재구조화로 종결)
    ⑵ 정보-맞춘 격리 replay: 격리서 해소 → **부하** → 결정론 분리/controller
    ⑶ 잔존 → **능력/경계** → learn(도메인-일반 preference)·ASK·scale.
(c) 모든 개입에 반대편 계측 게이트(Δspurious≤0·over-block·회복률) 필수.

**종속항 후보**: h(π) 추정기(패러프레이즈 궤도·flip율 Wilson 하한) / 오류 계약 포맷
(diagnosis+suggestions=스키마에서 결정론 계산) / per-argument ask-counter(stuck=같은 인자
ask k회∧binding 0) / **slot 소스 구분**(producer-도구-반환 vs 유저-발화·W1) / **유저-위임
실행 노드**(give→user-실행 이벤트 대기 게이트·W2) / grace-turn(K-턴 유예+escape act·W3) /
확인-vs-재요청의 act-타입 구분(W4) / done_report 봉투 통합 / 문법의 A2-파생 자동 컴파일 /
처방-등급별 강제 예산(강제 ε≈0·표면화 완화).
