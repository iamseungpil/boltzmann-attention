> ★**이 문서가 유일 정본. F1-F6·G1-G9·BC0-7·N1-N4 코드는 전부 폐기(deprecated).** 앞으로 이 이름만 쓴다.
> 이유: 이름을 계속 새로 만들어(F→G→BC→N) 혼란. 서술형 이름 하나로 통일.
> 3축: **①관찰 현상**(추론 없이 셈) · **②근본 LLM 기능**(원인·reasoning 읽어야 앎) · **③해결 레버**(고치는 법).

## 축2 · 근본 LLM 기능 (원인·11개·anchor)
| # | 근본기능 | 정의(왜 실패) | 결정론 가능? |
|---|---|---|---|
| 1 | **준수** | 정책·확인 술어 미집행 | ✅ 게이트 |
| 2 | **완결** | 요구 단계/항목 미완 — *및 완료 오판정(자기검증 실패)* | ✅ 게이트(실상태) |
| 3 | **조립** | 선행자원 수집·도구 발견·계획을 부하로 놓침 | ✅ controller |
| 4 | **계산** | 집계·비교·기준값 기호 연산 오류 | ◑ calc/thinking |
| 5 | **참조** | 의도→올바른 대상/속성 의미 매칭 실패(⋈) | ✗ 경계 |
| 6 | **지속** | 장기 절차서 per-step 복리 붕괴 | ◑ scale/분해 |
| 7 | **중단판단** | 조기 포기/과잉 지속(escalate 타이밍) | ◑ read-only 게이트 |

| 10 | **부재판정** | 없는 정보를 종결 못하고 검색 루프 | ✅ 부재-종결 게이트 |
| 11 | **유도** | dual-control 사용자 지시 실패 | ◑ 지시 scaffold |

3계층: **오프로드(준수·완결·조립·부재판정·실행규율)** = 결정론 / **레버로 사는 능력(계산·지속)** = thinking·scale / **환원불가 경계(참조·형식화)** = 모트.

## 축3 · 해결 레버
결정론 게이트 · controller · calc offload · provenance 게이트 · thinking · 경계/ASK · scale·fleet · learn · (게이트 하위: 완결게이트[실상태]·실행강제·부재종결)
- 비용순 **게이트≺controller≺calc ≺ learn ≺ ABox ≺ scale**. 부작용 없는 것 = 게이트(read-only)·calc뿐(나머지는 측정된 상쇄로 합성).

## 3축 × 4도메인 (per-case 확정)
| 도메인 | 관찰 | → 근본기능 | → 해결레버 | 근거(per-case) |
|---|---|---|---|---|
| **retail** | 값오류(변형) | **참조** | thinking/경계 | t79 "1000ml black"→오변형 |
| | 날조값(주소) | **형식화** | **provenance 게이트**(GO) | t17 "123 Elm St" 날조 |
| | 필수write누락 | **완결** | 완결게이트 | |
| **airline** | 선택인자 과채움(baggage) | **실행규율** | 인자-기본 게이트 | t8 "no bags"→2 (gold 9/9=0) |
| | 값오류(예약 ⋈) | **참조** | 경계 | reservation ⋈ 23% |
| **telecom** | 조기 escalate | **완결**(자기검증) | **완결게이트[실상태]** | "exhausted all steps" 믿음·실제 미해결 |
| | 다중결함 누락 | **완결** | 완결게이트 | MMS권한·리필 미수정 |
| **banking** | 절차 부분수행 | **조립** | **controller** | t043 gold7→3만(81%) |
| | 설명만·실행無 | **실행규율** | 실행강제 controller | t001 카드 추천만 |
| | 비종결루프 | **부재판정** | 부재-종결 게이트 | t014 없는 프로그램 검색 |

**★핵심 2가지**: (1) **완결·중단판단은 4도메인 불변**(도메인-일반 게이트=TBox). (2) **같은 관찰(값오류)도 도메인마다 다른 근본기능**(retail=참조 / airline=실행규율) → 도메인별 per-case 필수.
