### 3-1. 결정 지점 A — msg[011]→[012]: **베낄 값이 문맥에 없었다**

grep 출력에는 doc_011 의 **파일명**(`doc_credit_cards_credit_cards__general__011.md`)은 있으나
`initial_transfer_to_human_agent_1822` / `_0218` **문자열은 0건**이다(sim 전 메시지 전수 검색 결과
두 이름의 등장 횟수 = **0**). 즉 이 시점 모델은 **베낄 수 없었다**.

### 3-2. 결정 지점 B — msg[008]: **브레이크의 열쇠를 우리가 먼저 쥐여줬다**

`a2/banking_knowledge.gate.json:50` `notice_text` = `"TRANSFER NOTICE: Would you like to be transferred
to a human agent?"` · 같은 gate 의 `ask`(:53) 축자에는 **정답 지시가 이미 들어 있다**:

> *"If a knowledge-base document defines a specific transfer or escalation tool for this situation,
> call THAT tool instead of the general one - the general transfer is only for cases no protocol
> document covers."*

문제는 그 문장이 **모델이 notice 를 발화하는 순간 함께 소진된다**는 점이다. msg[008] 은 아직
`transfer_to_human_agents` 를 **부르지도 않았고** 어떤 문서도 읽지 않은 시점인데, 그 발화만으로
`t2_prekb_patch.py:291 _notice_done()` 이 True 가 되어 `:544-547` 에서

```
if _notice_done(a2, msgs, fam):
    _mark("deny waived fam=%s (notice already announced)" % fam)
    denied.add(fam); continue
```

CHECK-FIRST deny 가 **영구 면제**된다. 그래서 두 턴 뒤 msg[012] 의 일반 이관은 아무 저지 없이
실행됐고, user-sim 은 시나리오대로 *"If at any point you are actually transferred to a human agent,
thank them and end the conversation"* 를 이행해 **에피소드가 종료**됐다 — gold 4행은 그 순간
도달 불가가 된다.

면제되지 않았을 때 나갔을 문구는 `t2_prekb_patch.py:196-205 deny_text()` 로, **정확히 필요한 처방**을
담고 있다: *"(1) call KB_search(query=\"…\") and read the results; (2) if a special procedure applies …
follow it exactly (including any internal tools it names) BEFORE '…'"*.

런 전체 계수: t7336 3개 로그에서 `deny waived (notice already announced)` **3회** ↔ 실제
`deny (no action-keyed KB evidence)` **1회** — 면제가 집행보다 3배 잦다.
