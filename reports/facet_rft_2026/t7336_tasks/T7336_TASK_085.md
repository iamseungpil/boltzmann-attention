## 8. 처방 후보 (수리 미실행 · 제안까지)

우선순위 순. 전부 [[70]] 의 판정 3종(전체 reward 짝 A/B · 태스크별 부호표 · 무엇을 팔았나)과

1. **[최우선·순수 버그] `_stale_call_ids` 의 성공 판정을 에러-형상으로**
   (`t2_gate_patch.py:1691-1692`). F8 수리(`t2_prekb_patch._argprod_hits`)와 **같은 술어**를 쓰면
   된다: `m.error` ∨ `content.lstrip().startswith("Error")` 면 성공 아님. 프레임워크 형상 판정이라
   도메인 리터럴 0. 부수로 **9981행 문구를 영어로 + "이미 완료" 주장 삭제**(사실이 아닐 수 있는
   문장을 손님에게 보내지 않는다·[[25]]). 이번 판에서 write 8건 삭제 + user-sim 오염을 만든 자리다.
   ※ 같은 `not m.error` 술어를 쓰는 다른 지점이 있는지 전수 grep 필요(같은 부류 재발 방지).

2. **[최우선] STEP2 가 지목한 이름을 `agent._t2_our_names` 에 등재**
   (`t2_resolve.py:496` 직전에 `agent._t2_our_names |= {_nm2}`). 읽기 루틴은 이미 그렇게 하고 있고
   (`t2_gate_patch.py:2691-2693`), `resolve_operator` 는 `T2_PROV_OURS=1` 에서 그 집합을 **레지스트리와
   교집합**해 쓰므로(`t2_resolve.py:170-171`) 날조 통과는 여전히 구조적으로 불가. 같은 이유로
   `T2_UNLOCK_PROV`(`t2_gate_patch.py:10424`)도 이미 `_t2_our_names` 를 본다 — **등재만 빠져 있다.**
   이번 판에서 3847 차단이 t0 의 유일 치명 원인이다.

3. **[높음] 퇴화 축(`_general_` 단독 클래스)에서는 `decide_from_docs` 결정문을 배달하지 않는다**
   (`t2_gate_patch.py:3407` 직전 가드). 술어는 닫혀 있다 — A2 `doc_index[group]` 의 클래스 집합이
   `{"_general_"}` 이면 "고를 것이 없다"는 **선언에서 기계 도출**되는 사실이고 도메인 판단 0.
   대안(더 보수적): `decided_by_docs_text` 를 write 결정점에는 붙이지 않고 read/조회 결정점에만
   붙인다 — 배달 값이 write 인자로 착지하는 경로 자체를 끊는다. 배달 문면의 *"It answers: X."* 는
   ⓐ고를 것이 실재할 때만 참이고 ⓑ그렇지 않을 때는 [[25]] 위반이다.

4. **[높음] E-PLAN L2 의 "미독" 술어에 *같은 목록 출력에 상세가 실려 있으면 제외*를 넣는다**
