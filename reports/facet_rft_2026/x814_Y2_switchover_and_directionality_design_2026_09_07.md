## §2. 방향성 d(ρ) — 논증을 **F1·F4 로 교체**

### 2a. 독립성의 유일하게 유효한 증거

`FOLLOWUP_REQUIRED / COVERAGE_FU`(F1) 와 `WRITE_EVIDENCE`(F4) 는 **감사 §2-A 코어**
= P닫힘 ∧ R닫힘(메뉴 ⑤/③) ∧ Q3 **전부 통과**다. 그런데 ⊖ 가 각각 **10 · 2** 로 공집합이 아니다.

> **P ∧ R ∧ Q3 를 전부 통과한 레버에 ⊖ ≠ ∅ 가 존재한다**
> — 이것이 d 가 두 축의 함수가 아니라는 **유일하게 유효한 증거**다.

⛔ F3 로는 성립하지 않는다(R열림). rev1 의 논증은 **재분류로 만들어낸 빈칸**이었다.
⚠ 단 이 문장은 **S1(x815) 이 ⊖ 를 재산출해 영속한 뒤에만** 인용 가능하다(B1).

### 2b. 정의 — d 와 **d_eff**

```
⊕(ρ) = { t : gold(t) 가 ρ 가 미는 행동을 요구 }
⊖(ρ) = { t : gold(t) 가 ρ 가 미는 행동의 반대를 요구 }

d(ρ)     = |⊖(ρ)| / |T|                              ← gold 만으로 산출        (런 0)
d_eff(ρ) = |⊖(ρ) ∩ { t : ρ 가 실제 발화한 태스크 }| / |T|   ← gold + 기존 로그  (런 0)
```

**d_eff 가 실제 위험량이다.** 술어가 ⊖ 태스크에서 발화하지 않으면 피해는 0이다.
술어가 닫혀 있으므로 **기존 코퍼스**(`results.gz` 746 · 사이드카 573)에서 **유료 0**으로 센다.

⇒ §0 의 *"미리 막을 수 있는"* 에 정면으로 답한다:
**gold + 기존 로그만으로 기대 피해를 배치 전에 잰다.**

### 2c. 독립성의 **범위 제한**

닫힌 처방 메뉴 5종 중 **④표면화**는 정의상 *"행동 요구 0"* 이므로 **d=0 이 구성적으로 따라온다**.

⇒ **d 는 R①②③⑤ 안에서만 새 정보를 준다.** 이 제약을 명시해야 축이 단단해진다.

| 축 | 대상 | 측정 | 판정 |
|---|---|---|---|
| **P** | 판정 | h(π) 궤도-조건부 엔트로피 | flip≥1 → 열림 [M] |
| **R** | 행동의 **형식** | 닫힌 메뉴 소속 | 정성 |
| **d** | 행동의 **내용** | ⊖/T · d_eff · **R①②③⑤ 에서만 유효** | §2d |

### 2d. 판정 규칙은 **비대칭**이다 (h(π) 규칙과 동형)

- **d = 0 → 증명**: gold 전수 열거에서 반대항이 **없음**. 태스크-집합 부작용 0.
  (⚠ 오탐 0 은 아니다 — 「참인데 형식 미달」은 남는다)
- **d > 0 → 피해의 상한일 뿐**: 그 자체로 유해 판정이 아니다.
  **d_eff 로 좁히고**, 그래도 > 0 이면 ⊖-짝 측정 의무.

```
현행 (C216):  강제 허용 = P ∧ R ∧ Q3
제안 rev2  :  강제 허용 = P ∧ R ∧ Q3 ∧ ( d = 0  ∨  d_eff ≈ 0  ∨  ⊖-짝 측정 통과 )
              R④ 표면화는 d 판정 **면제**(구성적 d=0)
```

⚠ rev1 §2e 는 d 를 **대칭 문턱**처럼 써서 F4(⊖=2)까지 강제 금지로 밀었다 — **과잉규제. 철회.**

### 2e. ⊕/⊖ 라벨러가 **열린 술어가 아님** (d 의 실제 약한 고리)

*"gold 가 반대를 요구"* 를 **누가 판정하는가**가 급소다.

> **정의**: `⊕/⊖` 는 `reward_info.evaluation_criteria.actions` 의 **도구명 집합**에 대한
> **닫힌 집합 연산**으로만 정의한다.
> ```
> ⊖(ρ) = { t : push(ρ) ∉ tools(gold(t))  ∧  block(ρ) ∈ tools(gold(t)) }
> ```
> `push(ρ)` · `block(ρ)` = **처방 → 행동 술어 사상**. **이것만이 도메인 몫**이며
> **A2 선언**(`lever_action_map`)에 둔다. 엔진은 집합 연산만 한다.

- 도구명 리터럴을 **엔진에** 넣으면 [[58]]·[[05]] 위반
- **LLM 이** 판정하면 P2b 프록시 = 열림
- ⇒ **A2 선언 + 엔진 집합연산**만이 통과 경로다

### 2f. **내부 선행** (신규성 주장 전 필수)

`go_stack.sh:475` 축자:
> `export T2_SPEAK_PROHIBIT=1   # E3-②(022): push 레버가 **돌고 있는 절차가 금지한 도구**를 권하지 않는다`

**채택**: `CORE vs FULL · 97 태스크 · nt=3` = **582 sim**
(rev1 예산 291 의 2배 · 클라우드 실측 처리량 기준 **~10시간 · ~$21**)

### 3c. 주 추정량 — **이중차분(DiD)**

`FULL − CORE` 는 **14 레버 묶음**이라 차이를 개별 레버에 귀속할 수 없다(감사: 레버별 해상도 없음).
그러나 **⊖ 집합이 gold 로 사전 지정**되므로:

```
Δ_DiD = ( FULL − CORE | ⊖집합 )  −  ( FULL − CORE | ⊖-여집합 )
```

여집합이 크므로(97 − |∪⊖|), 층-단위 묶음이어도 **"차이가 ⊖ 에 몰려 있는가"** 는 검정된다.

⇒ **주 추정량 = Δ_DiD.** 단순 부분집합 비교(rev1 §3b-③)는 **부차로 강등** — 팔 전체 수준 차이와 구분되지 않는다.
