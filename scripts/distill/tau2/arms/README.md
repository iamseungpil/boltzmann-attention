# 실험 팔(arm) config — 같은 sha · env 만 다르다

**왜 있나** 모델·서버에 매인 값(프로필 `model_profiles/*.env`)과 달리, 여기 있는 것은 **이번 실험에서
가르려는 축**이다. 같은 커밋으로 두 GPU 에 서로 다른 팔을 **동시에** 띄워 Δ 를 귀속시킨다([[54]]).

**규칙**
1. 팔은 **하나의 축만** 바꾼다. 두 축을 같이 바꾸면 Δ 를 못 가른다([[70]]).
2. 기본(`ctl`)은 **종전 거동**이어야 한다 — 대조군이 실험 전 상태다.
3. 값마다 **왜 그 값인지 한 줄**을 적는다(근거 없는 상수 금지·[[62]]).
4. 태그에 팔 이름을 넣는다: `bank_x72<티어>_t<티어><side>_<arm>_<날짜>`.

**사용** `run_ours_task.sh --arm viewscale <TAG> <PORT> <TASK_IDS>`
