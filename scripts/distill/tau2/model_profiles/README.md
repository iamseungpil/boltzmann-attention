# 모델 프로필 — 모델·서버에 매인 값만 여기 둔다

`run_ours_task.sh` 가 **서빙 중인 모델 id 로 자동 선택**하고, `--profile <이름|경로>` 로 덮을 수 있다.
파일명 = 모델 id 의 `/` 를 `__` 로 바꾼 것 + `.env` (예: `Qwen/Qwen3.8-27B-FP8` → `Qwen__Qwen3.8-27B-FP8.env`).

## 왜 파일로 빼나

2026-08-31 사고: `T2_GUIDED` 의 문법 표면형이 **hermes** 인 채로 서버만 `qwen3_coder` 로 바뀌어,
두 달치 런에서 네이티브 도구 파싱이 **전량 실패**했다(격리 x703: hermes 0/3 ↔ qwen3_xml 3/3).
같은 날 두 번째: `_ctx_fits` 의 캡 `44672` 는 Qwen2.5-32B 의 `max_model_len` 이고, 런 스크립트의
`T2_AGENT_MAX_TOKENS=3072` 는 정본 8192 를 근거 없이 덮고 있었다.
⇒ **모델을 바꿀 때 같이 바뀌어야 하는 값**이 코드·임시 스크립트에 흩어져 있으면 조용히 어긋난다.

## 규칙

1. 여기 있는 값은 **모델/서버가 정하는 것만**이다. 레버의 on/off 는 `go_stack.sh`(정본)에 둔다.
2. 값마다 **출처 한 줄**을 붙인다 — 서버 기동 인자, 실측 분포, 격리 번호. 근거 없는 값 금지.
3. 새 모델을 붙이면 프로필을 **먼저** 만든다. 없으면 `run_ours_task.sh` 가 발사를 거부한다.
4. 표면형은 선언만으로 믿지 않는다 — 발사 전 `x704_surface_preflight.py` 가 실제로 파싱되는지 잰다.
